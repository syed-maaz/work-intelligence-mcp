## Status legend

- ✅ **Implemented** — code matches the decision; verifiable against `src/`
- ✅ **Accepted** — decision recorded but not yet (or not separately) implemented
- ⛔ **Superseded** — decision overtaken by a later ADR; body kept as historical reference
- 📎 **Peer review** — supporting doc for another ADR

## Rule for ADR maintenance

1. Every ADR has a `**Status**:` line in its header (Accepted / Implemented / Superseded / Deprecated).
2. When you write a new ADR, add its row to this index **in the same commit**.
3. When you supersede an ADR, update both the superseded ADR's status field and this index.
4. ADR bodies are immutable once Accepted — append "Implementation Status" or "Update YYYY-MM-DD" sub-sections rather than editing prose.
