# Cypher loop trace — demo run

> **This page is auto-generated by `npm run demo:trace`** (`scripts/demo-loop-trace.mjs`).
> It is currently a **placeholder**: the generator script ships, but the run needs a real
> Anthropic API key because `runLoop` makes live (paid) model calls.

## Run this to generate

```bash
DATABASE_PATH=./data/demo.db ANTHROPIC_API_KEY=$KEY npm run demo:trace
```

The script imports `runLoop` directly (in-process — no bridge), runs one fictional goal over the
demo database (`./data/demo.db`, seeded by `npm run demo`), then reads back the `cypher_steps`
rows the loop wrote (one row per tool_use, ADR-038 v2.5 D18) and overwrites this page with an
**annotated** trace:

- **Goal** — the fictional demo goal (e.g. the PROJ-101 widget rollout on acme/widgets)
- **SCOPE refine** — whether a refinement pass ran, or the single-pass execute path
- **Tool picks, why eligible** — which catalog tools the posture exposes and why each pick is
  eligible (from the tool-catalog descriptions, not hand-faked)
- **Recall lanes hit** — which 9-lane recall surface the query touched, if any
- **EXECUTE** — status, duration, model reasoning per iteration
- **Verdict** — the loop's verdict and the `cypher_outcomes` Beta-prior signal written

Until the run happens, the real trace is not available; the generator is reproducible, so any
run with a key produces the page from the loop's own persisted audit rows.
